📌 SETUP GUIDE
🔔 안내: 구글 플로우는 수시로 UI가 업데이트됩니다. 이에 맞추어 오토플로우팩토리도 패치하여 업그레이드해서 배포하고 있으니 항상 앱 우상단의 종 모양 아이콘(공지사항)을 확인해주세요.
  1. 플로우 홈페이지 URL: labs.google/fx/tools/flow (클릭 시 새 탭에서 열기)
  2. 우상단 역삼각형 모양 필터 아이콘 클릭 후, 모든 필터 선택을 해제해주세요.
  3. 필터에서 정렬 기준을 '최신순'으로 체크하세요.
  4. Flow 초기 설정에서 '제출 시 프롬프트 지우기' → '사용' 으로 선택해주세요.
  5. 원하시는 모드를 선택한 후 진행해주세요. (대본투이미지모드 / 팩토리모드 추천)
  6. 팩토리 실행이 안될 경우, 우상단 점세개 → 번역 → 이 사이트 번역 안함
  7. 'Content Script 주입 실패' 오류 발생 시, chrome://extensions/ → FLOW FACTORY 세부정보 →
       # 다음 사이트에서 자동으로 액세스 권한 허용 버튼을 활성화해주세요
       # 파일 URL에 대한 액세스 허용 버튼을 활성화해주세요
  8. 지정한 폴더에 파일이 저장이 안되거나 프롬프트 번호대로 파일명이 생성되지 않는 경우, 다른 확장프로그램 버튼을 비활성화해주세요. (확장프로그램 간 경로 충돌이 원인입니다)
✨ 자주 묻는 질문

Q. 대본분석 후 프롬프트 생성이 안돼요!

→ 제미나이 무료 키 사용 시, 특정 시간대 사용자가 몰려 키 사용이 제한될 수 있습니다. 설정에서 무료키 모델을 다른 모델로 변경 후 재시도하세요.

→ API key 일일 한도 소진으로 생성이 안 될 수도 있습니다. 다른 계정의 API key를 새로 등록하거나, 유료 API key(더 똑똑한 모델)를 발급받아 사용하세요.

Q. 커스텀 캐릭터 레퍼런스가 잘 안돼요!

→ 대본 자동 모드가 아닌 개별 프롬프트 사용 시, 커스텀 캐릭터의 네이밍 또는 MCR/SC1/SC2 등 주·조연 분별 코드가 반드시 프롬프트에 들어가 있어야 매칭됩니다.

→ 대본투이미지/팩토리 모드는 AI가 자동으로 주·조연을 구분하지만, 대본 자체의 캐릭터 네이밍이 등록하신 네이밍과 일치해야 합니다.
